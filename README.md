# Forest-Scouting
Horror · Godot · Very early state of game

![screenshot](github_assets/ss.png)

## About the Game
The main story is about a forester who steps in to replace the previous employee for a while.

## Lastest update
Added gravity to the game and car object.

## Features
- working door
- walking, sprinting, crouching, zooming
- usable task list
- real time updating list of tasks
- gravity
